# Stocks 控制台布局重构方案（v2）

## 诊断：为什么现在「一眼 AI 图」

1. **135 个 Card 包裹一切** — 每个 UI 区块都是圆角白卡+边框+阴影，三层嵌套 Card
   （页面 Card > 区块 Card > 条目卡）造成「积木感」，这是 AI 生成界面的典型特征。
2. **统计数字做成 4 张大卡** — 4 个数字用 4 张带图标的卡展示，密度极低。
3. **列表项做成卡** — 检索命中、Run 列表、报告列表、积压条目全是 rounded-xl 卡片，
   列表本该是行，不是一摞卡。
4. **信息被卡框切碎** — 同一逻辑区域（如报告页的摘要/缺口/来源独立性/对照/用量/证据包）
   被拆成 6 张独立卡，视觉上互不相干。
5. **装饰性元素** — eyebrow 大写字母间距 tracking、衬线 editorial 字体、径向渐变背景、
   surface-grid 网格背景，这些「设计感」堆料是 AI 页面的另一特征。

## 设计原则（依 Apple/Emil 技能）

- **内容即界面**：数据密度优先，装饰为零。分隔靠间距与 1px 分隔线，不靠卡框。
- **ShadCN 原生组件优先**：Table、Tabs、Badge、Button、Alert、Separator、Skeleton、
  Dialog；Card 只用于真正独立的浮出内容（登录卡、确认对话框），页面内容不用。
- **层级 ≤ 2**：页面 > 区块（section 标题 + 分隔线），区块内直接是行/表格/定义列表。
- **列表用 Table 或 divide-y 行**；详情用 dl 定义列表；正文就是排版，不套框。

## 各页改法

### 全局
- 删 body 径向渐变、surface-grid；PageHeader 去 eyebrow 大写与衬线字体，
  改为普通 h1 + 右侧动作区，下缘 1px 分隔线。
- Card 组件保留但页面内容不再使用（登录页除外）。
- 新增 `<Section>`：`标题 + 描述 + 分隔线 + 内容` 的轻量区块（不是卡）。

### Overview
- 4 张统计卡 → 一行 4 列的**数字摘要行**（无边框：数字 + 标签 + 说明，分隔线隔开）。
- 研究覆盖/用量/近期 Run/Document/来源 → 改为 **Section + Table/dl**：
  - 研究覆盖：`dl` 4 项 + 缺口 Badge 行
  - 近期 Run：Table（任务/状态/创建时间/步骤）
  - 最新 Document：Table（标题/版本/完整度/采集时间）
  - 来源状态：Table（来源/采集状态/新鲜度/积压）
  - 近期报告：Table（标题/生成时间）
  - 用量：保留 dl + 模型列表

### Intelligence
- 检索表单不再包 Card：Tabs + 输入行直接放页头下，筛选仍是 details 折叠。
- 检索命中：卡 → **行列表**（divide-y）：标题+相似度 Badge / 元信息行 / 正文摘要 3 行
  / 展开定位。选中态 = 左侧 2px 主色竖线 + bg-muted/40。
- Document 列表：同样行列表。
- 详情侧：Document 详情从 4 张卡 → 单栏连续排版：
  标题区（dl 元数据 2 列）→ Separator → 处理状态（Table）→ Separator →
  片段（编号 + 正文 + 定位折叠）→ Fact（Table：指标/数值/单位/期间/定位）。

### Tasks
- 2 列大卡 → **Table**：任务/类型/启用/策略/最近 Run/操作（触发按钮行内）。
- scope JSON 收进行内展开（details）。

### Research
- 报告列表：卡 → 行列表（标题/时间/状态，选中态同 Intelligence）。
- 报告阅读：去掉大卡，正文直接排版（衬线仅正文）：
  标题 → 元数据行（as_of/证据包/选定/独立原件 一行 4 项）→ 截断警告 Alert →
  正文 → 缺口（Badge 行）→ 来源独立性（dl + 表）→ 对照（收进 Collapsible 或保留
  下拉 + 表）→ 指标对比（Table：指标/数值/口径/观测期）→ 用量（dl）→
  证据包（编号行：标题/版本一致性/片段/正文/定位折叠/Fact/原件按钮）。

### Runs
- 筛选区去卡框（行内表单）。
- Run 列表：卡 → 行列表（任务/状态/时间/错误行）。
- 详情：3 张卡 → 连续排版：头部 dl + 错误 Alert + 操作行 → Separator →
  步骤（每步一行：序号+类型+状态+耗时，错误行内联，输出折叠）→ Separator →
  模型调用（保留 Table）。处理积压：卡 → Table（Document/阶段/状态/尝试/操作）。

### 登录
- 保留单卡（唯一合理的卡用法），去重阴影与图标底色块，缩小标记。

## 不变
- 路由/URL 参数语义、交互逻辑、数据流、API 契约、可访问性（role/aria/键盘）。
- 现有测试语义相应更新选择器，断言行为不变。
