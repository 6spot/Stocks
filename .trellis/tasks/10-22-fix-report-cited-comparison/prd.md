# F-04：按报告实际引用比较历史证据

## 问题与目标

报告比较的 Document/Fact 集合目前来自初始入选与采用补证的全集，未按保存的 Analysis/Findings 实际引用过滤，还读取当前 Fact 表。目标是准确呈现两份报告的引用变化及对应历史值，不把未引用材料的取材变化当作报告依据变化。

来源：[审查 F-04](../10-20-stocks-roadmap/research/implementation-design-review.md)。父任务：[修复计划](../10-22-implementation-design-fixes/prd.md)。P2，硬依赖 [F-01](../10-22-fix-fact-reprocess-history/prd.md)；建议在 F-03 合入后集成统一的补证投影。

## 范围与约束

- 按已经保存、校验的报告引用确定 Document/Fact 比较集合，覆盖初始资料与补证。
- 比较的原值来自各自冻结输入，不重新研究、不现场再抽取、不改写旧报告。
- 只按现有引用可表达的粒度比较；不能推断模型未声明的 Fact 引用，不能用某文档全部 Fact 扩充。
- 保留原有成功 Run、两侧排序、Task/Scope/as_of 警告及原件入口，不重做报告阅读界面。

## 验收条件

- [ ] AC-1：两份报告均仅引用 A，第二份输入包多出未引用 B 时，不出现 B 的 Document 或 Fact 引用新增/修订。
- [ ] AC-2：实际引用新增/消失、同来源内容版本变化及同指标值修订仍正确展示，双方片段/原件可追溯；同时覆盖初始与补证引用。
- [ ] AC-3：从已保存的规范化引用确定集合，不遗漏 Findings 中的合法引用；同一引用在顶层/不同 Findings 重复出现不双算。
- [ ] AC-4：对来源执行同版本重处理、创建新版本或新增其它 Fact 后，再读旧报告比较，旧侧引用及原值不变；不为缺失字段静默补入实时值。
- [ ] AC-5：未成功 Run、错配/越权引用继续拒绝；无法确定的历史 Fact 数值如实标缺失，不伪造 0 或把整个输入包当作兜底引用。
