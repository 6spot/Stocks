# V1/V2 最终验收收尾与阶段归档核对

## 目标与授权

Owner 已授权核对、验证、写入范围收敛、归档满足条件的父任务并提交推送；不能归档的任务须写出具体缺口，不以已完成子任务数替代阶段最终验收。随后批准更新测试服务器 `/opt/stocks` 的 API/Worker 镜像；测试使用 Magpie，正式 Jev 保留官方配置。

## 六项范围决定

应用 HTTP、TLS 交由反向代理/CDN；跳过手机真机；不做物理 ARM；不要求真实返回货币费用的端点；SeaweedFS 足够；不做 SEC 全量 companyfacts/完整 JSON 链路。均记录为主动收敛/跳过，不记成真实验收通过。SEC 现有证据是 submissions JSON；不能把 companyconcept 可选方案写成已验证。

## 需求与验收

- [x] 在测试服务器任务隔离数据库，用当前词表和 Magpie，对已有真实 SEC 文档执行一次显式 classify reprocess；核对实际协议、模型、指纹和持久状态。
- [x] 保存分类前/后证据及原件、Document 版本、parse batch、Chunk 身份；明确成功替换当前 classification JSONB，不创建新解析批次；失败保留前次成功分类。
- [x] 六项决定同步到 docs/validation.md、路线图统一清单与父任务文档，已验证、范围移出、仍未验证分别如实记录。
- [ ] 父任务通过最终归档核对后归档；仍有未完成要求则保留活动任务并写明问题。

## 实际结果

Magpie 网关地址和调用凭据已从现有 Pi provider 配置自行取得，不需要 Owner 重新提供或写入正式 .env。隔离重分类已成功，实际原生模型 jev-1.14.0，词表版本 2026-10-27，指纹 023566a6ea4a236ae169774bcdff02334cfaf5e96746dfdd27d5e14a7af3c61e；详见 acceptance.md 和 verification/。

当前仍缺长期调度/cron/时区、应用真实限流/预算终止、完整真实 Tavily 补证 Run，以及晚提交变化流进入后续证据包的运行证据。Owner 六项决定未移出这些要求，因此不得无条件把三个阶段父任务标为完成。

## 非目标

不改分类/研究业务逻辑，不全量重处理，不增加价格估算，不修改正式端点，不把测试服务器的 451 外推到正式服务器，不把容器 uptime 当作持续调度验收。
