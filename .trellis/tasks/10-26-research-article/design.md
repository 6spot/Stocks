# 技术设计

## 生成契约

严格 JSON 输出新增 title、sections[{heading,body,finding_ids}]，findings 新增 id/title。正文与结构化发现由同一次研究生成；每个 Finding 必须在章节中使用，引用沿用已授权 EvidenceRef。空证据时允许无发现的诚实受限文章。后端检查关联与引用的结构有效性，不以关键词/篇幅判断文章质量。

## 存储与 API

Analysis 保存标题与章节，Report 使用真实文章标题并保存 Markdown 导出。报告详情返回结构化章节与发现。同步初始化结构，不做旧数据迁移/兼容。已有历史记录不主动重写；重建开发环境须限于本任务隔离环境。

## 展示

复用 Markdown 与已有证据交互。文章按主题渲染，章节引用使用一致编号；章节下展开相关发现，类型作为中文轻标签。研究资料与生成信息在页面底部默认折叠。原始引用/指标/冲突仍可访问。

## 边界

backend/config/docs/research 由后端子任务负责，frontend 由前端子任务负责，主任务负责接口整合、docs/interface、远程测试与交付。只在 100.120.14.84 的本任务隔离目录验证，不运行本地测试。
