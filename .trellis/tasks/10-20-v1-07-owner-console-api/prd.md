# V1-07 Owner 访问控制与控制台后端 API

## 目标与用户价值

跨设备开放前保护报告、原件和操作，并提供日常控制台所需查询及恢复接口。

## 背景与依据

阶段：V1。归属契约：`docs/interface.md`, `docs/execution.md`, `docs/data.md`, `docs/validation.md`。代码现状见[基线](../10-20-stocks-roadmap/research/baseline.md)，现有模型/helper 不等于业务闭环。

## 前置依赖

[V1-06](../10-20-v1-06-incremental-evidence/prd.md)

依赖是实施顺序，不由 Trellis 父子关系自动执行。跨阶段依赖先通过前一阶段验收。

## 范围与要求

- 单 Owner 访问控制覆盖 Web/API、历史原件与触发/重试/异常 Run 操作；凭据来自环境/安全配置，不建多租户权限平台。
- 提供 Overview、Sources、Document/Fact 检索详情、Tasks、Runs/步骤、研究报告和处理积压接口，返回稳定 Schema 和有界分页。
- 展示采集成功、来源更新预期、后处理积压三类状态；未配置 expected_freshness 不猜过期。
- 手动触发返回既有活跃 Run；重试/继续扫描/结束异常 Run 复用已实现服务，并守住确认旧执行停止的操作条件。
- HTML 原件仍安全返回，下载不得绕过认证；模型调用信息与错误脱敏。

## 验收条件

- [ ] AC-1: 未认证请求不能读取私有报告/原件或触发操作；Owner 能读取与操作，过期认证失效。
- [ ] AC-2: 来源无更新、Connector 失败、索引积压在 API 中可区分，分页不无界扫描。
- [ ] AC-3: 重复触发返回同 Run，重试和续扫可定位实际文档/阶段；结束异常 Run 需要显式确认旧执行停止。

## 不在范围内

多租户、配置可视化编辑器、向公网实际发布。

## 约束与规划状态

只改当前设计与初始化，不做旧库迁移或旧版兼容；运行期证据和历史引用仍须保留。此任务保持 planning；本轮未实施。开工前复核前置交付、实际文件和配置，再对本任务规划进行实施确认。
