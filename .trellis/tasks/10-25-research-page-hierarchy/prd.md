# 研究页信息分层：正文优先，次级内容 Tab 化

Owner 反馈：报告页「乱糟糟、什么都直接铺出来、没有主次」。页面定位是**阅读页**：
第一任务舒服读完报告，第二任务可下钻证据，其余是支撑信息。

## 三层结构（已与 Owner 确认）

### 第一层：始终可见
- 标题 + 状态 + 生成时间（一行）
- **信任摘要行**：独立原件 N · 引用 M 条 · （仅截断时）截断警告——读完正文抬头即知证据基础
- 缺口 Alert（仅非空）
- 报告正文（Markdown，75ch）

### 第二层：正文下方 Tabs（默认证据包；未激活的 Tab 不发请求）
| Tab | 内容 |
| --- | --- |
| 证据包 | E1..En 引用行（Fact/定位/原件收进折叠） |
| 来源与指标 | 来源独立性 + 同指标取值对比 |
| 研究用量 | 调用/Tokens/费用/模型明细 + 跳转 Run 链接 |

- **历史报告对照拿出报告页**：列表栏加「对照」入口（进入对照视图），不再常驻本页。
- **当前采集指针移到 Runs 详情**（运维信息，与阅读无关）。

### 第三层
- Runs 详情（经用量/页头链接进入）。

## 交互与契约不变
- URL 语义：`?report=` 选择保留；对照入口用新参数（如 `?compare=<id>` 或独立视图），
  深链接可用；两栏布局与初始选择逻辑不变。
- Tabs 未激活不请求 API（对照接口改为懒加载）。
- 证据/事实/对照/用量的展示语义与安全错误处理不变。
- `/api/reports/{id}/comparison` 契约不变，仅调用时机变化。

## 验收
- 首屏正文占比显著提升；除正文+信任行+缺口外无平铺区块。
- 未点开的 Tab 无网络请求；对照仅在对照视图中请求。
- 采集指针出现在 Runs 详情；报告页不再渲染它。
- 远程 typecheck/build/相关 vitest 通过；生产部署容器内核验（md5 同步 + 指纹核对）。
