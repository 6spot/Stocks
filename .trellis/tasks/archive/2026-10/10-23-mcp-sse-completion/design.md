# SSE 增量读取

保留普通 JSON 响应的 _read_body。SSE 在现有 _read_sse 中增量收取经过同一字节预算与时间检查的块，并按 SSE 行终止符组装事件。采用字节级行边界避免网络块切开 UTF-8 或 CRLF；完整事件才解码并解析 JSON。通知继续跳过，响应仍调用 _response_result 校验请求 ID 与协议。匹配响应事件结束后立刻返回已经接收的原始字节和结果，外层 httpx context 负责关闭响应。

事件数包括空事件，保持原有限额语义；无完整结果到 EOF 时返回既有明确协议错误。最后未终止事件的处理保持原有可接受输入，不新增宽松协议。不得使用无上限后台读取线程、请求重试或放宽任一限额解决连接等待。
