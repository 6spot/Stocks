# V0-02 统一采集入口与首个真实来源

## 目标与用户价值

Owner 能手动从一个真实已配置来源取得文章正文并通过统一入口保存。

## 背景与依据

阶段：V0。归属契约：`docs/data.md`, `docs/execution.md`, `docs/validation.md`。代码现状见[基线](../../../10-20-stocks-roadmap/research/baseline.md)，现有模型/helper 不等于业务闭环。

## 前置依赖

[V0-01](../10-20-v0-01-raw-document-versions/prd.md)

依赖是实施顺序，不由 Trellis 父子关系自动执行。跨阶段依赖先通过前一阶段验收。

## 范围与要求

- 提供 Source 文件配置与手动采集入口；首个可用 RSS/Atom + HTTP 正文路径验证真实来源，不恢复已删除的摘要式旧采集器。
- Source 范围内的新条目及明确更新均尝试获取；不按 Watchlist、投资价值或 should_ingest 过滤。
- Feed/链接只作发现；全文不可得时保存实际取得内容、原 URL、缺失及错误，不能用整份 Feed 冒充各文章原件。
- URL、重定向、响应类型/大小、超时及请求限额受控；来源更新信号触发复查，不定时遍历历史链接。

## 验收条件

- [x] AC-1: 至少一次真实来源采集可读取实际文章正文原件，并记录来源和真实时间；保存脱敏的人工验收记录。
- [x] AC-2: 重复发现及更新信号不重复制造版本；全文失败保留部分内容且明确不完整。
- [x] AC-3: 配置范围内与关注股票无关的文章仍入库，恶意 URL 或超限响应被拒绝并留下可诊断错误。

## 不在范围内

来源大全、定时采集、分类/Fact、外部 MCP 研究补证。

## 约束与规划状态

只改当前设计与初始化，不做旧库迁移或旧版兼容；运行期证据和历史引用仍须保留。本任务已完成实现、真实 SEC/S3 验收并归档，结果见 [acceptance.md](acceptance.md)。2026-10-20 归档审查发现畸形文章链接未按单项失败处理、采集丢弃 `Content-Type` 的 `charset` 两处缺陷，修复归属 [V0-08](../10-20-v0-08-document-collection-fixes/prd.md)。
