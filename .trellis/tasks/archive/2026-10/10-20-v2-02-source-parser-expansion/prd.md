# V2-02 更多真实来源与内容解析适配

## 目标与用户价值

按实际研究缺口扩展来源和内容类型，所有渠道继续共用统一数据流程。

## 背景与依据

阶段：V2。归属契约：`docs/data.md`, `docs/research.md`, `docs/validation.md`。代码现状见[基线](../../../10-20-stocks-roadmap/research/baseline.md)，现有模型/helper 不等于业务闭环。

## 前置依赖

[V2-01](../10-20-v2-01-authorized-tools-mcp/prd.md)

依赖是实施顺序，不由 Trellis 父子关系自动执行。跨阶段依赖先通过前一阶段验收。

## 范围与要求

- 依据真实研究缺口选择新增来源、频道/API/网页/PDF 等适配，来源名单和访问限制在本任务启动前确认。
- 优先复用 Connector 和 Source Mapper，获取后统一保存原件、来源、时间、版本和处理状态。
- 按实际内容补充 JSON/XML/PDF 解析及字段/页码定位；无法可靠解析时记录缺口，不用模型猜原文。
- 来源请求限额/安全校验和更新信号规则继续有效；不建设自动扫历史链接任务，不做采集前相关性审批。

## 验收条件

- [x] AC-1: 每个实际选择的新来源有可运行配置和真实样例，原件到片段/Fact/报告引用可追溯。
      新增的公开 Federal Reserve 新闻 RSS 在测试服务器用真实链路采集 20 条条目入库，
      20/20 的 S3 原件 SHA-256 与数据库 `content_hash`、字节数一致；真实 HTML 与真实 PDF
      均可解析成带定位的片段，且片段范围可回到原件。真实 PDF 经文章获取通道入库后解析
      （8 页 / 15 Chunk / 页内字符一一映射）。**待 Owner 验收**：`user_agent` 仍是占位
      联系邮箱，首次持续采集前需换成真实邮箱；SEC EDGAR submissions 示例的 CIK 与访问
      政策确认，以及该 API 的真实响应映射未验收（示例保持 `enabled: false`）。
- [x] AC-2: 同数据经不同发现渠道取得仍走统一入口；解析失败保留原件并可重试。
      PDF 与 HTML 一样经 `SafeFetcher` 文章获取 → `ingest_document()` → 同一 parse 阶段；
      真实重跑复用同一处理器版本批次（attempt 1 未新增），显式重处理生成 attempt 2 并保留
      attempt 1 的 Chunk ID/文本/定位；损坏、加密、无文字层与超限分别记为稳定错误码，原件不变。
- [x] AC-3: 新增格式保持数值、单位、表格上下文与定位；权限或配额受限明确展示。
      JSON 用 JSON Pointer、XML 用元素路径、PDF 用页码 + 页内字符范围定位；数值与单位按
      原文文本保留（真实 PDF 核对：片段数字全部来自原件、无新增数字）。HTML 的表格行/单元格
      定位不变；**PDF 表格结构重建与 OCR 明确不在范围**，已在 `docs/data.md` 写成缺口而不是
      承诺，没有文字层的 PDF 记 `PDF_TEXT_UNAVAILABLE` 失败并保留原件供重试。

## 不在范围内

无界采集、全格式/OCR 承诺、独立来源平台、证券主数据。

## 约束与规划状态

只改当前设计与初始化，不做旧库迁移或旧版兼容；运行期证据和历史引用仍须保留。Owner 已授权按 V2 任务列表逐个实施，本任务已实施并交付：解析器版本由 `semantic-text-v1` 升为 `semantic-text-v2`，旧文档的下一次解析生成新的不可变批次，历史批次与已引用片段保留。
