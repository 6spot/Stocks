# V2 阶段交付组织

本阶段保持既有系统边界，以子任务接入同一 Repository、Task/Run 与研究流程。目标：按需授权补证，更多实际来源、来源独立性、冲突、历史比较与覆盖费用分析。

父子关系只表示归属；依赖以子任务 prd.md / implement.md 和 task.json 的 meta.depends_on 为准，Trellis 不自动调度。按下列任务次序推进；编号是建议串行顺序，未相互依赖者可独立细化。

- [V2-01](../10-20-v2-01-authorized-tools-mcp/prd.md)：授权 Tool MCP 与研究按需补证
- [V2-02](../10-20-v2-02-source-parser-expansion/prd.md)：更多真实来源与内容解析适配
- [V2-03](../10-20-v2-03-source-conflicts/prd.md)：来源独立性与冲突证据呈现
- [V2-04](../10-20-v2-04-report-comparison/prd.md)：基于原始证据的历史报告比较
- [V2-05](../10-20-v2-05-coverage-cost-acceptance/prd.md)：覆盖费用与异常分析及 V2 验收

阶段父任务不直接实施；各子任务写有建议落点、契约来源和风险。初始化结构直接修改当前定义，不迁移旧库；运行期原件和引用持续保留。更换已确认的阶段范围必须回到领域文档和阶段验收一起调整。
