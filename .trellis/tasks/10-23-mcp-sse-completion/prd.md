# SSE 收到完整响应后立即完成读取

## 问题

客户端先等响应流 EOF 再解析 SSE。即使当前请求已有完整结果，后续保持连接或读取超时仍使调用失败。

## 要求与验收

- 收到当前请求的完整 JSON-RPC 结果后立即完成，不读取后续流。
- 支持跨网络块分割的 UTF-8、data 行、多行事件及 LF/CRLF/CR 换行。
- 结果前的通知/注释正常处理；错误、错配 ID、非法 JSON/UTF-8、缺少结果继续明确拒绝。
- 截止时间、累计读取字节、事件数和 JSON 深度限制继续有效。
- 在标准 McpClient 调用链以受控流验证结果后连接保持/异常的情形，复用现有授权及安全回归。
- 不新增外部连接或第三方依赖，不把受控测试写成真实 MCP 验收。
