## 验收路径（标准手动入口）

1. **新鲜联合采集**：以标准 CLI 入口对已配置来源跑一轮真实采集（不使用旧 Run 冒充），记录 Run id、各来源获取/入库/重复/失败数。
2. **处理完整性**：等待/驱动 parse→classify→facts→index 完成，记录最终阶段状态分布与积压。
3. **市场简报 Run**：手动触发 `market_intelligence_brief`，记录 Run/Report id、as_of、模型调用、usage、耗时、预算与缺口。
4. **个股报告 Run**：手动触发 `spacex_company_research`，同上记录。
5. **内容逐条核查**：对每份报告的关键结论逐条抽取「结论 → 引用 [E#] → Document/Fact → 原文」，核对数值/单位/期间/公司关联；检查事实/观点/推断标注、冲突与转载、迟到资料、覆盖缺口陈述。
6. **取样专项**：论坛观点（CNBC 评论性文章）、重复/冲突、公司直接信息与行业背景区分、历史 Facts（MP-02 修复效果）、迟到资料、关键遗漏。
7. **补证边界**：本轮两个 Task 配置未启用 Tavily 补证 → 按验收标准明确记录「未覆盖」，不以上游客户端独立成功冒充。
8. **清单汇总**：形成通过/失败/未覆盖/排除四类清单，内容问题归属到对应子任务，作为父任务集成复核输入。

## 记录方式

- 执行记录写入本任务 `acceptance.md`（Run/Document/Report id、模型、usage、耗时、缺口、逐条核查表）。
- 凭据、token、endpoint 明文不入任务记录；模型金额不可得时记 unknown/null。
- 已知限制如实登记：研究续扫 2 页输入 MODEL_TIMEOUT（4 个 Run 复现）；Tavily 补证未启用；交易复盘未启用。
- 不为通过验收修改数据或重跑通过项；失败的项如实标失败。

## 回滚

纯验收无代码变更；若验收暴露产品缺陷，登记到对应子任务或新任务，不在本任务内临时改代码凑通过。
