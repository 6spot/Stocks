## 一、真实内容修订样本（同 URL 正文级变化）

### 尝试 1：库内 22 份真实 SEC 文档与当前线上字节逐一对比

逐条比对 `stocks_both` 中 22 份 `sec_press_releases` 文档的线上当前字节与库内
`content_hash`：

| 结果 | 数量 | 说明 |
| --- | --- | --- |
| 字节一致 | 0 | — |
| 字节不同 | 22 | 全部为旧 63889 字节 → 新 63879 字节，固定差 10 字节 |
| 归一化正文一致 | **22 / 22** | 词数完全相同（如 2026-107 为 680 词对 680 词） |

对 2026-107 做行级 diff，唯一差异是文档尾部的防爬脚本：

```text
OLD: <script type="text/javascript" src="/-snhDb/14/VG/7x_s/..."></script>
NEW: <script type="text/javascript" src="/GZe8DtCUQibNucdSbQ/..."></script>
```

**结论：这是同一正文的防爬随机串变化，不是内容修订。** 若用它当“真实版本修订”，
就是把模板噪声说成来源更新，因此**不采用**。

### 尝试 2：寻找正文会真实更新的公开来源

| 来源 | 结果 |
| --- | --- |
| Apple CIK JSON（`sec_edgar_submissions`） | 当前 163917 字节、SHA-256 与库内完全一致，短期不会自然产生新版本 |
| Treasury `debt_to_penny` API | 可达，逐日数值不同（2026-10-20/21/22 三个不同值）；但每次是**不同 record_date 的新记录**，不是同一 Document 被修订 |
| Fed / SEC 官方 RSS | 可达；条目只提供首次发布与更新时间，观察窗口内无正文级修订 |
| BLS、Treasury 新闻、White House、CFTC、FDA RSS | BLS 403、Treasury 超时、White House 404；CFTC/FDA 可达但同样无正文级修订 |
| Federal Register API | 可达（单文档 JSON 2262 字节）；文档发布后不做正文修订，修订以新文档号发布 |
| Congress.gov API、GovInfo CREC | 403 / 超时，未取得 |

**结论：在本次有界探测内没有取得“同一 URL 正文级变化”的真实样本。**
真实修订需要在更长观察窗口内持续轮询真实来源，或由 Owner 指定已知会改稿的来源
（例如带勘误/更新说明的公告页）。本项**未完成**。

## 二、真实转载样本（声明同一原件）

### 尝试 1：官方 RSS 的 `<source>` 声明

| Feed | `<source>` 标签数 |
| --- | --- |
| Fed `press_all.xml`（14813 字节） | 0 |
| SEC `pressreleases.rss`（18571 字节） | 0 |

官方 Feed 不声明转载来源，无法用它们构造“同一原件、多个发布方”。

### 尝试 2：聚合器与转载站

| 来源 | 结果 |
| --- | --- |
| Google News RSS | 可达；`<source url>` 存在（100 个），但链接是 `news.google.com/rss/articles/...` 聚合跳转，其自身 canonical 指向 Google；无法直接解析出发布方原始 URL |
| 按标题检索 Google News | 确有多家媒体同题（如 The Motley Fool 与 Yahoo Finance 同题），但解析出的仍是 Google 聚合链接 |
| benzinga / streetinsider | 403 |
| businessinsider / finance.yahoo 对应 slug | 404 |
| globenewswire / investing.com | 403 |
| fool.com 文章页、nasdaq.com | 404 / 超时 |
| marketwatch / barrons | 401 |
| PR Newswire RSS | 可达（20 条），但同题 Google News 只回指 `prnewswire.com` 自身，未找到跨站转载方 |

### 尝试 3：区域性储备银行转载 Board 公告

St. Louis Fed、New York Fed、Philadelphia Fed 新闻页可达，但其 canonical 均指向**自身域名**，
不声明转自 `federalreserve.gov`；`stlouisfed.org/on-the-economy/2026/oct` 返回 404。

**结论：未取得“页面显式声明指向另一来源同一原件”的真实转载对。** 现有实现只按
`<link rel="canonical">`、文章 URL、Feed `<source>` 三类显式声明合并，不做跨站正文相似度
推断——因此没有声明就无法构成合格样本。本项**未完成**。
