# 前端 Hook 规范

当前仓库没有前端工程，也没有可观察的自定义 hook。以下约束只规定建立前端后的职责与避免项；具体命名和文件路径需在 V1-08 按实际代码补充。

## 职责

- 只有需要复用 React 状态或生命周期组合时才提取 hook；单一组件的短暂 UI 状态继续留在组件附近。
- Hook 以 `use` 开头，输入和返回类型显式，不用宽泛对象或隐式全局状态传递契约。
- 请求、AbortSignal、重试和错误状态属于数据访问边界；不得让 hook 自行实现服务端权限、运行占用或处理状态机。
- 证据上下文与搜索筛选需要复位时，使用明确的输入标识触发重置；不跨页面复用已经属于另一来源或任务的旧数据。
- 没有证据表明需要后台同步、乐观更新或缓存时，不引入额外状态或数据获取库。

## 安全与可访问性

外部 HTML 不作为信任的 React 内容注入；hook 返回结构化证据与安全文本。加载、空结果、失败、未索引和来源故障必须保持可区分。需要键盘或焦点管理的交互由组件和 hook 共同保证，实际行为在浏览器或组件测试中验证。
