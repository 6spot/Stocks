# 组件与样式规范

组件按清晰职责拆分；页面负责组合，通用组件负责可复用的交互或展示。Props 用 TypeScript 明确声明，避免通过宽泛对象、隐式全局状态或不透明的字符串约定传递数据。只有出现真实复用需求时才抽取共享组件，不预建独立组件库。

基础按钮、输入、弹窗等交互优先复用选定的 shadcn/ui 与 Base UI 原语；样式使用 Tailwind CSS，并保持焦点、禁用、加载和错误状态可辨认。对外部内容采用安全文本展示，避免未经审查的 HTML 注入。

页面和组件的目录应跟随实际功能边界保持可查找；目录模式形成后在此记录真实文件路径和最小示例，不把假设的目录树写成既定规范。

证据交互必须区分“实际引用片段或 Fact”和“打开原件”两个动作。界面先展示来源、Document 版本、位置、时间与单位，再提供原件查看或下载；HTML 原件不得直接注入页面执行脚本。空结果、加载失败、索引未完成、来源故障和无资料必须使用不同的可读状态。
