# Agent 执行边界与阻塞交回

## 适用范围

适用于主会话，以及经用户授权使用的子 Agent、审查和研究调用，与模型、平台和业务模块无关。
本文件规定执行与反馈方式，不新增任务状态、派发机制或自动中止功能。

## 核心规则

Agent 遇到妨碍任务继续的问题时，应先在当前授权范围、现有条件和约定预算内进行必要诊断。
若确认继续工作依赖其无法自行取得的条件、权限、输入或决策，或继续尝试已不能产生有效进展，
必须停止受影响的操作，报告阶段成果与具体阻塞，并把控制权交给能够解决问题的一方。
不得在条件未变且没有新诊断依据时重复尝试，也不得以工具调用、模型输出或进度刷新代替实际进展。

## 执行前确定边界

- 每次执行批次或子调用应有明确、可审查的交付和结束条件；定向复审以指定问题和变更为边界。
  新发现若需较大改动或超出授权范围，先记录证据及建议，交回协调，不默默扩大任务。
- 按任务风险与预计耗时设定时间、轮数或尝试预算，并说明达到边界时应返回什么。已有合理预算时沿用；
  未指定时由执行者或主会话作常规安排，不为例行预算另向用户请求确认。
- 使用现有工具支持的超时或次数限制执行相应预算；提示词中的时间目标不等于运行时强制限制。
  无法强制执行的边界须如实说明，不能声称已有自动中止或持久日志能力。

## 识别问题并决定下一步

工具报错本身不等于任务阻塞。可自主解决的问题允许有界诊断和修复；每次再尝试应有新证据、
条件变化、明确不同的诊断目的，或仍在预算内且有依据的瞬时故障恢复策略。
不要求所有问题都先重试；已知缺少必要条件时，不为凑次数重发同一请求。

| 情况 | 处理 |
| --- | --- |
| 编辑匹配失败、原因明确的测试失败等可恢复问题 | 重新读取必要信息或修复根因，只重跑受影响检查；在预算内继续 |
| 必要输入、权限、凭据或外部资源缺失且无法自主取得 | 及时说明缺少的条件，停止依赖该条件的操作，阻塞返回 |
| 需求冲突，或存在用户必须决定且现有授权未覆盖的取舍 | 给出证据、影响和可选方案，交回决策 |
| 解决问题需要扩大范围或超出现有授权 | 报告所需变化和建议，不擅自扩大范围 |
| 外部服务持续不可用，合理恢复尝试已耗尽 | 报告错误证据、尝试结果和恢复条件，阻塞返回 |
| 反复尝试无新增证据、产出或问题范围缩小 | 停止当前路径，报告无法收敛的原因与建议，由上层决定下一步 |
| 预算已到，剩余工作仍可继续 | 阶段返回，列出成果和剩余工作；不自动续期，也不伪装成外部阻塞 |

有效进展是新增相关证据、可审查的产出、验证结果，或明确缩小的问题范围。
运行时长、工具调用次数、模型输出量、心跳和进度刷新本身不构成有效进展。
没有工具活动只说明缺少工具活动证据，不能直接断言死循环或仍在有效工作。

## 反馈、保存成果与交回

- 阶段变化、失败或阻塞确认时及时公开说明：已完成什么、当前在处理什么、下一步需要什么。
  不以“继续尝试中”代替具体进度，不输出私有推理或敏感信息。
- 停止的是受阻操作；仍有明确、独立且已授权的工作时，可在剩余预算内完成，但不得因此延迟报告阻塞。
  保存成果到现有任务的 `implement.md` 或 `research/` 等适当位置，避免为记录进度另建平台。
- 子 Agent 把控制权交回主会话，不在无交互子进程内等待用户输入。主会话能解决的自行处理，
  仅把确实需要用户提供的条件或决定交给用户；已有输入和授权不重复索取。
- 接收方先检查阶段成果和终止原因，再决定恢复条件、缩小范围、调整方法或安排下一批。
  条件和方法未变时，不原样重新派发同一受阻任务，也不丢弃已有成果从头开始。
- 返回前说明相关进程是否仍在运行、资源是否保留及原因；无法确认时写明未知，避免把返回当成进程已停止。

## 返回内容

以下是报告结论，不是新的 Trellis `task.json.status` 或机器可解析协议：

- **完成**：本批次交付和结束条件已满足；区分本批次完成与整个任务完成。
- **阻塞返回**：继续推进依赖某个条件、方法或决策变化；准确指出缺少什么，或为何当前路径无法收敛。
- **阶段返回**：预算已到或约定阶段结束，仍有可继续的工作；说明剩余范围。

返回应包含：

1. 结论与本次负责的范围。
2. 已完成的产出及文件或证据位置。
3. 问题事实、已尝试的方法及结果；诊断不确定时区分事实和推测。
4. 实际验证结果，以及失败、跳过或尚未运行的检查。
5. 继续所需条件或决定、建议的下一步，以及仍在运行的进程与保留资源。

不要只说“失败了”或“连接不上”，也不要把部分成果或进程零退出码当成整项验收通过。

## 示例

- **可自主恢复**：编辑上下文不匹配 → 读取目标片段 → 修正编辑；无需交给用户。
- **阻塞返回**：已确认依赖服务不可用且有界恢复失败 → 保存修改，报告错误与缺失条件，相关检查标未验证。
- **阶段返回**：定向审查已完成两个问题的核查，预算到时尚有一个待查 → 返回证据和剩余问题，不宣布全项通过。
- **错误做法**：没有新证据仍反复重读、修改和重跑；每次超时后原样再派发；把界面刷新当作持续有效进展。
