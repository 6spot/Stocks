# Web 界面与报告展示

本篇定义面向单一 Owner 的页面和报告交互，不重复定义 Analysis 或 Evidence 的存储契约；参见 [研究设计](research.md) 与 [架构总览](architecture.md)。

## Web 产品界面

V0 采用响应式单人研究工作台，不开发 UI 组件库，不制作图形化 Agent/Task 工作流编辑器。布局由 Stocks 自己定义，基础按钮、弹窗、输入与交互原语使用 shadcn/ui + Base UI。

主要视图：

- Overview：采集覆盖情况（最近成功采集、来源错误、分类/抽取积压）、近期研究报告与运行状态，可定位失败或待处理的 Document。
- Intelligence：按来源、公司名称/股票代码、**类别、主题、行业、地域**、时间及全文/语义检索 Document 与 Fact；无股票标签或标签有歧义的文档仍能通过原文检索发现。
- Tasks：任务名称、类型、可选策略、上次执行、状态和手动触发。
- Research：按时间、研究任务和范围查看综合报告、关键数据、分析依据、历史报告和资料缺口；可直接查看 Document/Fact 原始证据。
- Runs：任务执行步骤、模型调用、费用、错误与回退信息；可查看积压/失败文档的来源、采集时间、最近尝试、错误和重试状态。

第一版的来源、模型、Agent、策略、任务和工具均以 YAML/Markdown/.env 管理；Web 只提供必要的查看与触发能力，不重复开发配置编辑系统。

### 统一 Research 阅读与证据交互

市场、行业、个股使用同一个报告阅读界面，章节依据研究目标及实际证据动态呈现，不强制空栏目或空图表。

| V0 报告字段 | 用途 |
| --- | --- |
| `report_id`、`run_id`（可选 `analysis_id`） | 关联本次研究和运行 |
| `title`、`objective`、`scope` | 标题、研究目标、范围 |
| `as_of`、`changes_window`、`generated_at` | 研究知识截止、增量窗口与生成时间 |
| `summary`、`sections[]` | 摘要、章节及可选表格/图表 |
| `evidence_refs[]`、`coverage` | 实际 Document/Fact 引用及缺失、过期与冲突 |
| `previous_report_ref?` | 可选历史报告引用 |

基本交互：

1. **阅读研究**：显示主要变化、结论、理由、风险、不确定性和相关数据；失败 Run 不替换最后成功报告。
2. **追溯证据**：点击引用查看来源与原文位置或 API 数值，显示发布时间、来源最后更新时间（若有）、采集时间、版本和单位；可继续查看 Repository 的原始资料。
3. **查看历史**：按时间打开之前的成功报告，并依据真实来源比较判断变化；无需专用 Finding 关系图、Verifier 状态或独立核查界面。

报告附近说明不可用来源、资料缺失、重要冲突或候选截断，不能把未核实推断标成事实。图表值只能从已存 Repository 数据得到。Web 桌面和移动端共享内容，只调整导航与证据详情的响应式布局；配置仍通过 YAML/Markdown/.env 完成。
